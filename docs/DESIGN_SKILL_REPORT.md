## 2. Harmonization & Conflict Prevention

To avoid conflicting aesthetics (e.g. tasteskill's editorial white space vs. cyber workstation dark mode):
1. **Atmosphere Harmonization**:
   The dark palette (`#060911` base) is anchored by `tailwind-design-system` and `ui-ux-pro-max`, while `design-taste-frontend` prevents marketing "slop" by mandating that every section has real product UI and plain, factual copy without buzzwords.
2. **Animation Discipline**:
   `emil-design-eng` and `choreograph` govern all motion: strictly zero animation on keyboard shortcuts and slider dragging, reserving fluid spring motion only for state changes (tab sliding, dossier cascade, modal mounts).
3. **Typography Discipline**:
   Sans-serif (`Inter`, `system-ui`) is used for all narrative and headings; monospace (`ui-monospace`, `Consolas`) is reserved exclusively for cryptographic hashes, coordinates, telemetry numbers, and code.

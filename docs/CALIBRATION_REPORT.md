## 1. Executive Summary

In forensic image analysis and judicial evidence reporting, an raw classification score must **never** be presented as an empirical fraud probability without rigorous calibration. 

This report documents the probability calibration protocol implemented in VeriSight Pro:
1. **The Hand-Tuned Heuristic Baseline is UNCALIBRATED:** The overall composite score ($0$ to $100$) generated by Layer 4 linear weighting has a Brier score of **$0.3308$** on synthetic development data.
2. **Learned HistGradientBoosting (GBDT) achieves optimal probability calibration:** Using 3-fold Platt Sigmoid calibration, GBDT achieves a Brier score of **$0.0992$** on development cross-validation.
3. **Decoupling Operational Triage from Fraud Probability:** The operational threshold of **87.0/100** represents a **high-priority forensic triage setting** for human investigator queueing, **not an 87% posterior probability of fraud**.

## 4. The 87/100 Operational Threshold Decoupling

A critical finding of this audit is ensuring mathematical clarity between:
1. **The Heuristic Composite Anomaly Index ($S \in [0, 100]$):**
   $$S = 1.35 \times (w_1 S_1 + w_2 S_2 + w_3 S_3 + w_4 S_4)$$
   This index represents physical and geometric anomaly intensity. A score of $87.0$ indicates that multiple independent forensic layers (e.g., ELA + baseline drift) spatially intersect at the same transaction locus.
2. **The Calibrated Posterior Probability ($P \in [0.0, 1.0]$):**
   $$P(\text{Tampered} \mid \mathbf{x}) = \text{CalibratedClassifierCV}(\text{GBDT}(\mathbf{x}))$$
   This represents the calibrated likelihood of forgery given the 11-dimensional feature vector.

**Enforced Protocol in UI & Reports:**  
VeriSight Pro now explicitly renders both values side-by-side with distinct labels:
* `Risk Index: 88.0 / 100 (Operational Triage Alert)`
* `Calibrated Probability: 80.6% P(Tampered | x)`
* Explicit disclaimer: *"The triage score reflects multi-spectral anomaly intensity; it does not replace banking ledger verification."*
